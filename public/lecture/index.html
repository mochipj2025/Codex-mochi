Run of Show

講義の進行メモ

  1. 0〜5分ゴール紹介。「今日は5枚＋再利用できる手順を持ち帰ります」
  2. 5〜12分固定条件と変更条件の違いを説明
  3. 12〜25分講師実演：1枚目を生成して観察
  4. 25〜38分参加者実践：1枚ずつポーズを変更
  5. 38〜46分背景透過・ファイル名・余白を確認
  6. 46〜55分成功手順をSKILL.mdへまとめる
  7. 55〜60分共有・質問・次回案内
生成待ちの時間は、隣の人と固定条件を見せ合う時間にします。待ち時間を「観察」に変えると講義が止まりません。

Live Demo

実演用プロンプト

1枚目の生成に使い、成功後はポーズの1行だけを差し替えます。

背景透過ステッカーを1枚生成してください。 主役: 小さなカピバラ 画材: 色鉛筆と少しワックス感のあるクレヨン 雰囲気: 1960年代ヨーロッパのレトロ絵本 配色: クリーム、焼けたオレンジ、くすみミント、濃い茶色 顔・体型: クリーム色の口元、小さな丸い耳、濃い茶色の楕円の鼻、短くて丈夫な体型 ポーズ: 正面を向き、片手を振って、やさしく笑う 固定条件: キャラメル色の毛、焼けたオレンジ色のネッカチーフ、同じ顔・体型・画風・色 実際のアルファチャンネルを持つ完全な透明背景。全身を入れる。文字・ロゴ・透かし・余計な小物は入れない。

Plan B

失敗時の予備画像

生成が混み合う、背景が透過できない、キャラクターが変わる場合は、このセットを使って確認工程へ進みます。

切り替えの合図：生成を2回修正しても進まない場合は、予備画像で透過確認とSKILL.md化へ進みます。授業のゴールは「生成を待つこと」ではありません。
