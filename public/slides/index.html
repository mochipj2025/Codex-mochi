Today’s Goal

今日、持ち帰るもの

  • 同じキャラクターのステッカー 5枚
  • 透明背景の確認方法
  • 成功手順をまとめた SKILL.md

Rule 01

変えないものを、
先に決める。

色・顔・体型・持ち物・画材。固定条件が、キャラクターの「同じ」を守ります。

Rule 02

まず1枚。
それから次の1枚。

一気に5枚つくらず、基準画像を確認してからポーズと表情だけを変えます。

Observe

違いを見つけたら、
短く直す。

「鼻の形を1枚目と同じに」「ネッカチーフを戻して」。直す場所をひとつに絞ります。

Transparent PNG

白い背景と、
透明な背景は違う。

色のある面や市松模様に重ねて、輪郭の外側まで確認します。

Make It Reusable

成功した順番を、
SKILL.mdに残す。

次回の自分が迷わないように、固定条件・順番・確認・修正方法をまとめます。

Let’s Start

小さく試して、
5つの「できた」へ。

うまくいかなくても大丈夫。観察して、ひとつだけ変えて、もう一度。
