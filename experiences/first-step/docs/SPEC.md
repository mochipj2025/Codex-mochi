# Codexの教科書：コピペ中心の入口・実装仕様

更新日：2026-09-04。Claudeへの引き継ぎ用。変更前に実際のソースとGitの差分も確認すること。

## 目的と決定事項

ユーザー方針は「学習よりすぐ使える、簡単、迷わない」。初めて使う人が、用意された文章をコピーしてCodexに貼り付け、画像を作って保存できることを第一の成功体験とする。

- サイト名は「Codexの教科書」。個人の活用ガイドで、OpenAI公式ではない。
- 案内役は「もちスラくま」と頭の上の「もちっと芽ちゃん」。ユーザー提供の設定資料を基準とする。
- 最初のおすすめは「コピーして1枚作る」。文章を考えたり入力項目を埋めたりする準備を必須にしない。
- キーボード操作やショートカットを先に教えない。説明は必要なときだけ折りたたみ内で、マウス中心に案内する。実装上のキーボードアクセシビリティは維持する。
- アプリの準備、学習教材、勉強会は必要な人が選ぶ補助導線。
- GitHubは既存の `mochipj2025/Codex-mochi` にまとめるとユーザーが指定。別リポジトリは作らない。

## 動作仕様

このサイト自身は画像生成を実行しない。利用者のCodexで生成する。Codexの画面・進捗・利用上限・ファイル保存結果をサイトから取得できない。待機時間を推測して完了にしたり、実際の進捗らしい数値を表示したりしない。

- コピー：Clipboard API成功時だけ次へ進む。失敗時は全文を開いて選択し、手動コピーの確認ボタンを表示。
- 1枚の練習題材はカピバラ。案内役のもちスラくまと制作見本は役割が異なる。
- 5枚制作：最初の参照画像を固定し、手を振る・おじぎ・ありがとう・ばんざい・おやすみを個別PNGで作る。見本が不明なら添付を求める。同名上書きを避け、上限やエラーでは未完成番号を明記する。
- 保存は本人の確認。5枚は開いて確認できてから成功扱いにする。
- localStorageの `mochi-easy-start-preview-v1` にstepのみ保存。入力内容・ファイル・認証情報は保存しない。不正データや保存不可でも使えるようにする。
- 700px / 370px等でレイアウトを調整。CSS実装済みだが実機・拡大表示は未確認。

生成時に市松模様が焼き込まれたため、ユーザーの明示指定でローカル画像処理により背景を除去した完成版を採用した。アルファと暗色・明色での境界を確認済み。市松模様の元画像を完成素材と取り違えない。利用許諾の範囲を今回新規に判断しておらず、リポジトリに包括的な素材ライセンスを追加していない。

manifestはアイコン情報を提供する。Service Worker・オフライン対応・PWAインストール保証はない。

## 実装状況と残課題

実装済み：コピペ中心の入口、1枚と5枚の手順、途中再開、コピー失敗の代替、端末内の続き保存、透過素材、favicon・タッチアイコン・manifest、トップと準備画面の透過素材適用。

自動検証の対象：静的ビルド、リンクと素材参照、コピー成功・失敗、再開文。画像の寸法・アルファと素材見本も確認する。今回の実行結果は引き継ぎ記録を参照。

未実施・未確認：

1. 初見ユーザーが説明を受けずに1枚保存まで進めるかの試用。
2. 実ブラウザでのクリック、Clipboard権限、Windows/Macの貼り付け・保存、狭い画面・200%拡大。
3. 手順画面の案内役をカピバラからもちスラくまへ統一するかの判断。練習見本はカピバラで維持。
4. 公開サイトへのトップ・導線・アイコンの移植。公開ルートと図書館の保護を維持すること。
