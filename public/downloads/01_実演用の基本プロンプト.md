# 第1回 Codex勉強会｜実演用プロンプト

## 実演のゴール

同じキャラクターに見える、背景透過のステッカー画像を5枚、1枚ずつ作成します。

## 最初に入力する基本プロンプト

```text
色鉛筆で描いた海外ヴィンテージ絵本風の、眠そうなカピバラのゆるキャラ。
1960年代ヨーロッパの伝統的なお菓子の缶に描かれているような、少しガーリーなレトロイラスト。
暖かい茶色、くすみミント、クリーム色、落ち着いたコーラルを使用。
2頭身の丸い体型、半分閉じた眠そうな目、丸い頬、小さな口、柔らかな色鉛筆の線と紙の質感。

このキャラクターの顔、体型、頭身、配色、線の太さ、色鉛筆の質感を全5枚で統一してください。
変えるのは、各画像で指定するポーズ、表情、小物だけです。

背景は完全に透明。床、風景、影、光の輪、白背景、文字、枠、透かしは入れないでください。
全身を枠内に収め、手足や耳を切らず、周囲に十分な透明の余白を確保してください。
1回につき1枚だけ生成し、完成を確認してから次の画像へ進んでください。

1枚目：基本の立ち姿。少し眠そうな表情で、両手を体の前に添えている。
```

## 2枚目以降の追加指示

毎回、直前に完成した画像を基準にします。基本設定を変更せず、以下の「今回の変更点」だけを差し替えます。

### 2枚目｜お菓子

```text
直前の画像と同じキャラクターとして作成してください。
顔、体型、頭身、配色、線、色鉛筆の質感、背景透過を固定します。
今回の変更点だけ：小さなキャンディーを両手で持ち、うれしそうに微笑む。
1枚だけ生成してください。
```

### 3枚目｜あいさつ

```text
直前の画像と同じキャラクターとして作成してください。
顔、体型、頭身、配色、線、色鉛筆の質感、背景透過を固定します。
今回の変更点だけ：片手を上げて、眠そうな顔のまま小さく手を振る。
1枚だけ生成してください。
```

### 4枚目｜びっくり

```text
直前の画像と同じキャラクターとして作成してください。
顔、体型、頭身、配色、線、色鉛筆の質感、背景透過を固定します。
今回の変更点だけ：両手を頬に添え、目を少し開いて驚いている。
1枚だけ生成してください。
```

### 5枚目｜おやすみ

```text
直前の画像と同じキャラクターとして作成してください。
顔、体型、頭身、配色、線、色鉛筆の質感、背景透過を固定します。
今回の変更点だけ：座って目を閉じ、小さな枕を抱えて眠っている。
1枚だけ生成してください。
```

## 失敗したときの短い修正指示

### 別の顔になった

```text
ポーズ以外が変わっています。直前の画像と同じ顔、目、口、頬、頭身、丸い体型、配色、線の太さに戻してください。変更するのは今回のポーズだけです。
```

### 背景が残った

```text
キャラクターは変更せず、背景だけを完全な透明にしてください。床、影、光の輪、白背景、縁の色残りを除去し、透明情報を持つPNGにしてください。
```

### 体が切れた

```text
同じキャラクターの全身を枠内に収めてください。手足や耳を切らず、周囲に十分な透明の余白を追加してください。
```

### 5枚が1枚になった

```text
画像を並べないでください。今回は指定したポーズのキャラクターを1体、1枚の画像として生成してください。
```

## 実演時の確認順

1. 顔と眠そうな表情
2. 2頭身の丸い体型
3. 暖かい茶色とくすみ色
4. 色鉛筆の線と紙の質感
5. 全身が切れていない
6. 背景が本当に透明
7. 1枚だけ生成されている
